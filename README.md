# rbx2nbx
CLI program that converts Roblox files (.rbxl) to Nedizblox (.nbxl)

# Usage
```bash
Usage: rbx2nbx [OPTIONS] <INPUT>

Arguments:
  <INPUT>  

Options:
  -o, --output <OUTPUT>  
      --from <FROM>      [default: Workspace]
  -h, --help             Print help
  -V, --version          Print version
```
